白璧是一个非常强大的封号工具，依照白璧制作者请求，破解白璧为白璧找出漏洞

### 开始之前
白璧是一个非常高级的扩展，我对其严谨感到非常惊奇，从禁用开发者选项到跳转，每一点都看出来白璧作者的用心
## 破解原理
对白璧的破解成本非常高，我也消耗了4天阳寿才完成
1. 白璧会每隔一段时间侦测是否打开开发者选项，如果有，就启动断点，所以纯js是行不通的，从我学过的语言来说，python是浏览器交互性仅次于js的（C++和C#还有C据我所学过的并不好用），所以我们可以用python注入
2. 白璧通过浏览器原生DOM来创建一个全屏div来完成封屏，这是最简单却又最不安全的，用代码注入直接删除就可以了
3. 白璧的跳转是最难搞的，它使用location.replace ("about:blank")来实现跳转，我又没有好好读MDN最新文档，导致我搞了好久啊（我以后一定好好读MDN文档，妈妈）
4. 然后一切就结束了
